Split-mode test

Put the controller in split mode, then run this. It records which gamepad (index + id) each half reports as. Per the manual, split mode (yellow light) is switched on in the Infinix app and resets to combined mode at power-off. If a half still shows the old name without -L/-R, reconnect Bluetooth.

Press Start to begin.

Joy-Con view (GT NX split mode)

Shows each half as a Joy-Con using the measured profile (gtnx-split-profile.json). Press a physical control. The chip that lights should be the control you pressed. If a different one lights, that row of the profile is wrong. Big text is the label printed on the hardware; small text is the Switch role.
